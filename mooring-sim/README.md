# 系缆方案浏览器推演台

横风叠加落潮工况下，对靠泊船舶做时间步准静态平衡推演：拖放编辑泊位俯视图，
录入各缆长度/刚度/安全载荷/预张力，设置分时潮位、风向风速、吃水、受风面积，
动画同步显示船体偏移、各缆张力利用率与未平衡载荷；支持停用缆绳、调预张力、
双方案并排回放，输出最早失衡时刻、主导载荷、首先失效缆绳，并生成可打印靠泊简报。

## 运行

零第三方依赖（仅 Python 3 标准库）：

```bash
python3 app.py
# 浏览器打开 http://localhost:5000
```

数据存入同目录 `mooring.db`（SQLite，首次启动自动建表并写入演示场景/两套方案）。
删除该文件重启即可恢复出厂数据。

## 目录

## 物理模型（mooring.py）

- 平面三自由度：纵移 X、横移 Y、首摇 ψ（小角度）。
- 每根缆为三维张力型弹簧：桩与导缆孔有高差（桩顶高程 − 导缆孔高程 − 潮位），
  实际缆长 `L=√(水平距²+高差²)`，张力 `T=max(0, k(L/L0−1))` 沿 3D 缆向，
  对船体取水平分力；松弛不承拉。**潮位逐时间步改变高差→缆长、垂直角、水平分力，
  落潮提缆会把横缆拉紧/提前超载**。
- 缆长来源：自动时取安装时刻（初始船位、初始潮位）的三维几何长度；
  **手填长度即安装时的实际缆长**，直接决定有效无载原长
  `L0_eff = L_install/(1+T0/k)`：缩短→初始应变/张力增大、更早超载，
  加长超过几何长度→初始松弛。
- 外力：风力 `½ρ C A v²`（纵/横向阻力系数分开），水流力（湿表面×吃水），
  首摇力矩按 sin(2θ) 经验律；环境关键帧间线性插值（风向走最短弧）。
- 护舷：沿岸侧舷边按间距（默认 30m）离散的线性反弹，贴泊即接触（2cm 容差），
  单具达到额定反力后截断；其切向刚度用中心有限差分，接触/脱离边界光滑。
- 每个时间步从安装船位重新做准静态 Newton 平衡（阻尼回退、物理容差
  0.15kN/30kN·m），缆绳用解析对称切向刚度；任一缆张力越过安全载荷即判失效、
  退出受力，外层主动集重解，实现“超载/松弛后受力重新分配”的级联；
  全缆失效时以极弱参考约束防止数值漂移，残差即“未平衡载荷”。

## 界面操作

- 拖放：拖动船体改变泊位、拖导缆孔（黄色小点，局部坐标）、拖缆桩（灰色圆）、
  拖缆绳靠船端的圆点可改接到别的导缆孔；双击海面新建缆桩，双击缆桩改名。
- 引线：工具栏选缆型 → “从船首导缆孔引线（再点缆桩）”→ 在图上点目标缆桩。
- 缆参数：侧栏“缆绳”表内联编辑，或选中后在详情面板改长度（取消“自动”可手填）、
  刚度、安全载荷、预张力、启停。
- 环境：“环境分时”页按时刻录潮位/风向°/风速/流速/吃水/纵/横受风面积；
  风向是“风推船的方向”，90° 即自海向岸横风。
- 画布：滚轮缩放、Shift+拖动平移；编辑后自动求解（约 0.35s 防抖）。
- 时间轴：上区各缆利用率曲线（100% 红线、✖ 为失效点），下区未平衡载荷，
  虚线为潮位；点击/拖动定位播放头，红底为失衡时段。
- 双方案对比：顶栏“双方案对比”选甲/乙两方案，并排俯视图+迷你时间轴同步回放，
  底部给出最早失衡时刻、首断缆、最大残余/偏移与推荐方案。
- 打印简报：“打印简报”在新窗口生成含船/泊位、环境表、系缆表、峰值利用率、
  俯视图与时间轴快照、评估结论的 A4 简报并调用浏览器打印（可另存 PDF）。

## REST 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /api/scenarios | 场景列表 |
| GET/POST | /api/scenarios[/&lt;id&gt;] | 详情 / 保存（DELETE 删除） |
| GET | /api/scenarios/&lt;id&gt;/plans | 方案列表 |
| GET/POST | /api/plans[/&lt;id&gt;] | 详情 / 保存（DELETE 删除） |
| POST | /api/simulate | body `{scenario, plan}` 或 `{scenarioId, planId}`，返回 `{steps, summary}` |

`summary` 含 `balanced / firstImbalance / firstFailure{lineId,name,time} /
maxResidual / maxDisplacement / maxUtil / maxUtilTime`；每个 step 另含
`strain`（各缆应变）、`vAngle`（缆与水平面夹角，潮位直接驱动）、`length3d`。

## 演示工况结论（种子数据）

横风 14→30 m/s 叠加落潮流速最高 2.4 m/s、潮位 +2→−3.2 m、历时 6h
（桩顶高程 4.0m、导缆孔 3.5m，落潮使横缆高差与垂直角增大）：

- 方案A（常规 6 缆，横缆安全载荷 450 kN）：t≈3.2h 两根横缆首先越过安全
  载荷失效，首/尾/倒缆利用率瞬间抬升（受力重分配），t≈5.0h 其余缆陆续断裂、
  进入失衡，最大未平衡载荷约 1300 kN。
- 方案B（加强 8 缆，横缆安全载荷 2000 kN、较低预张力）：全程平衡，
  峰值利用率约 95%。
- 潮位对照：同风同流（20 m/s、1 m/s）下，恒定高潮 +2m 与涨潮工况横缆不断，
  落潮工况约 4.4h 首横缆断裂，证明潮位逐时步参与几何/载荷计算。
